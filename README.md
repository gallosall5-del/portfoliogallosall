# Portfolio — Gallo SALL

Portfolio de **Gallo SALL**, développeur Full-Stack et mobile basé à Dakar (Sénégal).

- 💻 Accueil en 3D : un bureau de développeur interactif (chaque objet ouvre une section)
- 🌍 Une scène 3D par page : carte de Dakar, sphère de compétences, escalier des diplômes, carrousel de téléphones
- 🌗 Mode clair / sombre, responsive mobile

## Technologies

React 18 · Vite · Three.js · React Three Fiber · drei · Bootstrap

## Lancer le projet

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # site compilé dans dist/
```

## Modifier le contenu

Tous les textes sont dans `public/profile/*.json` (accueil, à propos, compétences, formation, expériences, projets, réseaux). Les scènes 3D sont dans `src/components/three/`.
